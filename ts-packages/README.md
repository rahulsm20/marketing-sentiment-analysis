# Typescript Packages

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run index.ts
```

This project was created using `bun init` in bun v1.2.18. [Bun](https://bun.sh) is a fast all-in-one JavaScript runtime.

This directory includes all packages across all typescript services in this repo

- Includes:
  - db models
  - logging utils
  - storage utils
